## 🏛️ What's Inside

| Pillar | Features & Tools |
| :--- | :--- |
| **🇮🇳 Central Schemes** | 69 verified Government of India schemes (SISFS, MeitY TIDE 2.0, BIRAC BIG, CGSS, PRISM, NIDHI) with eligibility, funding caps, and official portal links. |
| **🗺️ 3D Walkable Ecosystem Map** | Immersive 3D Indian terrain (Three.js) with 220+ incubator pins, elevation data, and state startup policy drawers. |
| **🧭 Scheme Finder Wizard** | 5-question interactive decision tree guiding founders to relevant grants by stage, sector, and entity type. |
| **⚡ 10-Section Knowledge Stack** | Front-mattered markdown operating system (`01-company` through `10-pulse`) preventing AI hallucination. |
| **🤖 19 AI Execution Prompts** | Production-ready prompts for Bootstrap, Gap Scan, Unit Economics, List of 100, Pitch Deck, and Weekly Recaps. |
| **📝 10 Actionable Worksheets** | Customer interview notes, competitor teardown, 2-week experiment, SOP entries, and trade order sheets. |
| **📊 Venture Studio / Portfolio Layer** | 1-5 cohort maturity rubrics, venture theme analysis, and coach meeting records. |

## 🚀 Quickstart

```bash
# 1. Clone the repository
git clone https://github.com/Aayush-Rajaji/venture-stack-india.git
cd venture-stack-india

# 2. Build the documentation site into docs/
node build.mjs

# 3. Preview locally
python3 -m http.server -d docs 8000
```
