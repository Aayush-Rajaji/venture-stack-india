# Worksheets

The repeatable artifacts — things you produce over and over, rather than the living sections in `stack/`.

Copy one, fill it in, save it where it belongs.

| Worksheet | Use it for | Lands in |
| --- | --- | --- |
| [startup-prep.md](startup-prep.md) | Preparing for a coach, mentor or investor session. 45–60 minutes. **Start here if the full stack feels like too much.** | `stack/CONTEXT.md` and across sections |
| [weekly-recap.md](weekly-recap.md) | The weekly pulse. Thirty minutes, every week, forever. | `stack/10-pulse/recaps/` |
| [customer-interview.md](customer-interview.md) | One per customer conversation. Guide plus note format. | `_inbox/`, then `stack/02-customer/` |
| [competitor-profile.md](competitor-profile.md) | One per competitor worth understanding properly. | `stack/03-market/` |
| [list-of-100.md](list-of-100.md) | Building and working a prospect list in one channel. | `stack/05-gtm/` |
| [experiment.md](experiment.md) | One risky assumption, one test, one number, two weeks. | `stack/04-product/` or wherever the assumption lives |
| [sop-entry.md](sop-entry.md) | One per repeated procedure. | `stack/06-operations/` |
| [trade-order-sheet.md](trade-order-sheet.md) | The sheet that lets a shop or distributor say yes. | `stack/05-gtm/` |
| [one-pager.md](one-pager.md) | Investor, institutional and channel variants. | `stack/08-capital/` |
| [advisor-scope.md](advisor-scope.md) | **Before anyone receives equity.** Role, deliverables, vesting, term. | `stack/01-company/` |

---

## If you only do three

**[startup-prep.md](startup-prep.md)** — because it surfaces which parts of your business you cannot currently describe.

**[weekly-recap.md](weekly-recap.md)** — because it is the only part of this system that compounds.

**[advisor-scope.md](advisor-scope.md)** — because undocumented equity promises are the most expensive cheap mistake in early companies, and the bill arrives at the worst possible moment.
