---

**The boundary.** This file records how to work with someone, not what you think of them as a person. Written well, it is the file that makes the fifth coach as useful as the first. Written badly, it is a personality dossier that will be read aloud back to you at some point.

The test is the same one that governs everything in [`docs/safety.md`](../../docs/safety.md): **write it as though they will read it.** If a line here would embarrass you in that room, it is not an observation about how to coach them — it is an opinion, and it belongs in a dated `[ASSESSMENT]` in [`reads/`](reads/) with your name on it, or nowhere.
